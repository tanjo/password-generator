# パスワード生成器

文字種と長さを指定してパスワードを生成する、ブラウザー上で動作するアプリです。乱数生成にはWeb Crypto APIを使用します。

## 使い方

1. パスワードの長さを4〜64文字で指定します。初期値は12文字です。
2. 使用する文字種を選びます。小文字・大文字・数字・記号は初期状態で有効です。ひらがな・カタカナは必要に応じて有効にしてください。
3. 「生成」を押すと、選択した文字種からパスワードを生成します。
4. 「コピー」を押すと、通常のパスワード出力をクリップボードにコピーします。

「記号」を有効にすると、文字種の一覧の下に記号の個別選択肢が表示されます。初期選択は次のとおりです。

```text
! @ # $ % ^ & * ( ) _ - + = . ?
```

その他の記号も個別に有効化できます。

ひらがなまたはカタカナを有効にしてパスワードを生成すると、通常の出力の下にURLエンコード版も表示されます。

## 開発

Node.jsとnpmが必要です。

```sh
npm install
npm run dev
```

本番用ファイルは次のコマンドで `docs/` に生成されます。

```sh
npm run build
```

ビルド結果をローカルで確認する場合は、ビルド後に実行します。

```sh
npm run preview
```
